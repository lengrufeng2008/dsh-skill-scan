# Notice

`dsh-skill-scan` is a static, read-only first-pass scanner for DeepSeek Harness skill/plugin bundles.

It is inspired by the supply-chain scanning idea of
[NVIDIA SkillSpector](https://github.com/NVIDIA/SkillSpector); no source code is copied. The rules here
are a small independent set of text heuristics, not a port of SkillSpector's engine.

A PASS is not a security certification.
